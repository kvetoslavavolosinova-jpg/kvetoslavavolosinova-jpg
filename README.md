## Supply Chain Supplier Compliance & Performance Analytics

**Python | Pandas | SQL | SQLite | Power BI**

End-to-end supply chain analytics project transforming raw supplier, order and compliance data into management-ready insights.

The project includes:

- Data cleaning and validation with Python
- Relational data loading into SQLite
- SQL joins, CTEs and window functions
- Supplier performance analysis
- On-Time Delivery KPIs
- Supplier compliance and ESG analysis
- Supplier risk classification
- Performance scoring and ranking
- Management reporting
- Interactive Power BI dashboard

### Key Results

- 15 suppliers analyzed
- 30 purchase orders
- €496,500 total order value
- 40% overall On-Time Delivery
- 73.07 average S-Rating
- 12 High Risk suppliers identified
- Supplier performance scoring and ranking implemented
